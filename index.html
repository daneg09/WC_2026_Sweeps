Auto-Update Architecture

This dashboard reads from data/tournament.json. A GitHub Actions workflow runs twice daily, fetches football-data.org, normalises the result, and commits the updated JSON. The API key never reaches the browser.

Schedule config .github/workflows/update-data.yml 
on:
  schedule:
    - cron: '0 6 * * *'   # 06:00 UTC
    - cron: '0 18 * * *'  # 18:00 UTC
  workflow_dispatch:        # Manual run
